# ⚡ Think Charge — Advanced Quiz & Assessment Platform

Think Charge is a full-stack quiz and assessment platform designed for managing large-scale quiz events with precision, automation, and real-time administrative control.

It features role-based access, QR-driven attendance, strict timing workflows, automated grading, and dynamic ranking — making it ideal for structured evaluations and live event environments.

# 👑 Master Admin Capabilities

### 📊 Dashboard Controls
- View all teams
- Delete teams
- Apply advanced filters

### 📁 Bulk Team Upload
- CSV import system
- Built-in upload instructions

### ⏱ Quiz Time Management
- Pre-configured quiz schedule

### 🚫 Misconduct Control
- QR scan to ban a team

### 🔓 Lock Open Key System
- Unlock quiz interface at the correct time

---

# 📱 Attendance Admin System *(Mobile-Optimized)*

### 📊 Attendance Dashboard
- View groups where attendance is closed/open
- Monitor attendance status

### 🕒 Smart Attendance Window
Allowed only:

- 30 minutes before quiz  
- 15 minutes after quiz start  

Auto-absent if not marked.

### 📷 QR-Based Attendance
- Scan team QR
- Mark:
  - All members present
  - Selected members present/absent

### 📋 Live Attendance Reports
- Present teams list
- Absent teams list
